# وب‌سایت مهندس قادر علی حسینی شام اسبی

وب‌سایت رسمی و پورتفولیوی تخصصی مهندسی برق، آسانسور و پله‌برقی.
طراحی شده با استایل مدرن **Liquid Glass** و تایپوگرافی فارسی **شبنم**.

## آدرس وب‌سایت
[https://ghaderalihosseini.github.io/](https://ghaderalihosseini.github.io/)

## حوزه‌های تخصصی
- **مهندسی برق صنعتی و اتوماسیون:** طراحی تابلو برق، درایو، مدارات فرمان و حفاظت.
- **سیستم‌های آسانسور:** آسانسورهای کششی و هیدرولیک، محاسبات ترافیک، استاندارد EN 81.
- **سیستم‌های پله‌برقی:** درایو، سنسورهای ایمنی، بازرسی و اورهال تخصصی طبق EN 115.
