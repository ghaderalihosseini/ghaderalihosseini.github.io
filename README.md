# وبگاه شخصی و تخصصی مهندس قادر علی حسینی شام اسبی

وب‌سایت شخصی و پورتفولیوی مهندسی سه‌بعدی (3D) با استانداردهای کامل **SEO و Schema.org**، طراحی مدرن و واکنش‌گرا (موبایل فرست با Bottom Navigation Bar)، پیاده‌سازی شده با **React 19, Vite, Three.js, Tailwind CSS و Lucide Icons**.

---

## 🚀 ویژگی‌های کلیدی

### ۱. معماری فوق‌پیشرفته سئو (SEO & Structured Data)
* **تگ‌های معنایی (Semantic HTML5):** ساختار سلسله‌مراتبی کامل با رعایت عناوین `h1` تا `h4`، تگ‌های `article`, `section`, `nav`, `main`, `footer`.
* **متا تگ‌های جامع:** کلمات کلیدی هدف نظیر `قادر علی حسینی`, `قادر علی حسینی شام اسبی`, `مهندس برق`, `مترو تهران`, `مهندسی پله برقی`, `استاندارد EN115`, `زاده اردبیل`, `متولد ۹ فروردین`.
* **داده‌های ساختاریافته Schema.org (JSON-LD):** ثبت گراف کامل اطلاعات شخص (Person: نام، زادگاه اردبیل، تاریخ تولد، شغل، سازمان متبوع مترو تهران و تخصص‌ها) و نمایه وب‌سایت (ProfilePage & WebSite).
* **فایل‌های موتور جستجو:** شامل `sitemap.xml` و `robots.txt` در پوشه عمومی.

### ۲. شبیه‌ساز سه‌بعدی پله برقی (Three.js 3D Engine)
* مدل تعاملی سه‌بعدی متحرک پله برقی مترو با خطوط ایمنی زرد رنگ استاندارد EN 115، سازه فلزی خرپا، نرده شیشه‌ای و حرکت روان استپ‌ها.
* قابلیت درگ و چرخش آزاد زاویه دوربین توسط کاربر.
* پنل کنترل تعاملی: تغییر حالت به وایرفریم (Wireframe)، کنترل سرعت حرکت پله‌ها و چرخش خودکار.

### ۳. تجربه کاربری موبایل (App-like Mobile Bottom Nav)
* منوی شیشه‌ای پایین صفحه (Bottom Navigation Bar) اختصاصی موبایل برای دسترسی سریع به ۵ بخش اصلی با نشانگر نئونی فعال.
* هدر بالایی شیشه‌ای (Glassmorphism) مجهز به افکت پالس وضعیت فعالیت زنده در مترو تهران.

### ۴. بخش‌های تخصصی
* **بیوگرافی:** داستان زندگی از اردبیل و زادروز ۹ فروردین تا ورود به مترو تهران.
* **کالبدشکافی فنی پله برقی‌های سنگین ترافیکی:** بررسی سیستم‌های محرکه، زنجیر استپ، ترمز کمکی، تابلو PLC و اینورتر VFD.
* **محاسبه‌گر زنده مهندسی EN 115:** تخمین زنده ظرفیت جابجایی مسافر و توان نامی موتور بر اساس سرعت و شیب پله برقی.
* **پروژه‌های شاخص در متروی تهران:** اورهال پله‌های برقی عمیق، بهینه‌سازی انرژی، سیستم‌های پایش وضعیت SCADA.
* **وبلاگ و مقالات تخصصی:** ۴ مقاله مهندسی کامل و کاربردی با قابلیت باز شدن در پنجره مطالعه اختصاصی.
* **فرم ارتباطی تعاملی:** با افکت شلیک کانفتی پس از ارسال.

## 🛠️ دستورات اجرا و توسعه

### اجرای محلی (Local Development)
```bash
npm run dev
```

### ساخت نسخه نهایی (Production Build)
```bash
npm run build
```

### انتشار مستقیم روی GitHub Pages (Deploy)
```bash
npm run deploy
```
*(پس از ایجاد مخزن گیت‌هاب و افزودن ریموت، این دستور پروژه را بیلد گرفته و روی شاخه `gh-pages` منتشر می‌کند).*
